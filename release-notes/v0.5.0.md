Live candles now stream through the Vost server, a health light shows how each exchange is doing, and the layout adapts to phones and tablets.

## Highlights

- **Live candles from the server**: live data now comes over a same-origin server-sent-events stream, `GET /api/live`. The server keeps one websocket per exchange feed, shares it between all open tabs and reconnects on its own; the browser opens no websocket and no cross-origin connection. After a reconnect the chart backfills the bars it missed.
- **Chart Range loads any span**: applying a chart Range outside the loaded bars now fetches that span from the provider (or generates it for Demo) instead of asking you to load more bars first.
- **Connection health light**: a dot in the top bar shows whether each exchange's price history, symbol lookup and live stream work right now. Click it for latency, last-ok time, the error text and a Test now button. It is backed by the new `GET /api/status`.
- **Pine tab**: Pine indicators are edited in a new Pine tab in the bottom dock with a full-height editor, an indicator selector, run status, errors and script inputs. Sidebar Pine rows gain an Edit button.
- **Resizable panes**: drag (or use the keyboard on) the sidebar and bottom panel handles; double-click resets them. Sizes are saved with your preferences.
- **Responsive layout**: at 900px and below the sidebar becomes a slide-in drawer, less-used top bar controls move into a More menu, the dock tabs scroll, and dialogs fit phone screens.
- **Dev and test tooling**: the dev container now ships Playwright Chromium and ffmpeg and is published as `ghcr.io/cbundy/vost/dev`, capture failures name the missing browser library, a test-only fake market-data service backs new network-audit and outage capture scenarios, and dev-system is updated to 0.101.1.

## Upgrade notes

No breaking changes. Saved browser data stays compatible with 0.4.0 (the new pane sizes load as defaults when absent).

- **Reverse proxies**: `/api/live` is a streaming endpoint. Add the `location /api/live` block from `docs/DEPLOYMENT.md` (`proxy_buffering off`, a long `proxy_read_timeout`), or the proxy will hold back or cut the stream.
- **Outbound traffic**: the server now probes the exchanges in the background for the health light, about 17 small requests a minute. Set `VOST_STATUS_INTERVAL=0` to turn this off.

To deploy, build from the tag (`git checkout v0.5.0`, then `docker compose up -d --build`); no registry image of the app is published.
