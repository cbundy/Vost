Old Pine scripts now get a plain message and a one-click conversion to v6, and the release adds a UI and server audit of Vost with the tooling used to produce it.

## Highlights

- **Fix: old Pine scripts**: pasting a Pine v1 to v4 script, or one with no `//@version` line, used to fail with a confusing parser error. It now shows a plain message naming the version, with a **Convert to v6** button in the Pine tab and the Backtest tab's Pine editor. The conversion is one undoable edit; anything it cannot convert safely is left as written and marked with a `TODO(convert)` line. Pine v5 and v6 scripts are unchanged. See the new Old scripts section in `docs/PINE.md`.
- **UI and server audit**: `docs/spikes/ui-audit/README.md` walks through every pane (its purpose, state owner and data source) and records 18 front-end and 5 server findings, each with steps to reproduce and commit-pinned evidence, plus the follow-up issues proposed to fix them.
- **Capture tooling**: new `ui-audit` and `pine-convert` capture scenarios (`npm run -s e2e:capture -- ui-audit`), and a server probe (`node docs/spikes/ui-audit/probes/server-probe.ts`) that starts its own fake upstream and servers, exercises the API with bad and slow inputs, and writes a raw log.

## Upgrade notes

No breaking changes. Saved browser data, the API and deploy config are unchanged from 0.5.0.

To deploy, build from the tag (`git checkout v0.5.1`, then `docker compose up -d --build`); no registry image of the app is published.
