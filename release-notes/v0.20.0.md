A small feature release: F1 now opens the built-in manual from any Vost page.

## Highlights

- **F1 opens the manual**: press **F1** on the chart, the compare page or the strategy maker to open the built-in manual in a new tab, the same one the Help button opens, instead of the browser's own help page. It works while typing in a field or with a dialog open; a held key or F1 with a modifier does nothing. The Help button's tooltip now names the shortcut. See [The manual](https://github.com/cbundy/Vost/blob/v0.20.0/docs/guide/getting-started.md#the-manual).

## Upgrade notes

- **Nothing to do.** No change to saved data, the API, the dependencies, environment variables, Docker, volumes, proxy setup, outbound network access or deploy config. Upgrading from v0.19.1 and downgrading back are both safe.

To deploy, build from the tag (`git checkout v0.20.0`, then `docker compose up -d --build`); no registry image of the app is published.
