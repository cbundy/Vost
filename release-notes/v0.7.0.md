The drawing rail grows: text notes, a temporary measure tool, a magnet, hide all and delete all, and drawing by touch on phones.

## Highlights

- **Text notes**: pick Text and click (or tap) the chart to type a note in place; Enter saves, Escape cancels. Double-click (or double tap) a note to edit it. Notes can be selected, moved, deleted and undone, and are saved per symbol like other drawings.
- **Measure**: drag, or click then click, between two points to see price change, percent, bars and elapsed time in a shaded box (green up, red down). It is temporary: never saved and not in undo, it clears on the next press, Escape or a rail pick.
- **Magnet**: a switch on the rail snaps anchors and handle drags to the nearest bar's time and its open, high, low or close (a horizontal line snaps price only).
- **Hide all and delete all**: hide every drawing without deleting it, or delete all drawings for the current source after a confirm (one undo step brings them back).
- **Touch drawing on phones**: below 600px the chart toolbar has a Drawing tools button that opens the same tools as the rail. Tap, tap places a line; one-finger pan and pinch zoom work as before in cursor mode.
- The drawing rail now scrolls when the window is short.

## Upgrade notes

No deploy or config changes: no new environment variables, server API, files on disk or Docker changes. Saved browser data is unchanged: drawings gain an optional `text` field and preferences gain optional magnet and hide-all switches, which load as off from older data.

To deploy, build from the tag (`git checkout v0.7.0`, then `docker compose up -d --build`); no registry image of the app is published.
