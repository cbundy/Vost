Time ranges and time zones for the chart and the backtester.

## Highlights

- **Chart Range**: a Range control in the chart toolbar crops the loaded bars to a From/To window, and clears back to the full data. Cropping is refused while live streaming is on.
- **Backtest time range**: a From/To range in the Backtest panel limits the backtester and the Optimizer to a window of the loaded data. The range is remembered between sessions.
- **Time zone clock**: a clock in the bottom dock picks the time zone, and every date on screen is shown in that zone. Candle times stay UTC.
- **Reset view**: a Reset view button in the chart toolbar re-fits all the data and restores automatic price scaling on every pane. It replaces Fit all data.
- **Top bar**: the top bar now shows the loaded data range and bar count.
- **Dev tooling**: dev-system updated to 0.99.1.

No breaking changes: saved browser data, the API and deploy config are compatible with 0.2.0. The time zone and backtest range are new optional saved preferences. To deploy, build from the tag (`git checkout v0.3.0`, then `docker compose up -d --build`); no registry image is published.
