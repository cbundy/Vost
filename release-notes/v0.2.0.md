The first tagged release of Vost.

## Highlights

- **Pine Script**: a Pine Script runtime (PineTS, with worker support), Pine indicators drawn on the chart with strategy markers, a CodeMirror Pine editor with highlighting, autocomplete and error markers, and backtesting of Pine strategies from the Backtest panel and the Optimizer.
- **Watchlists**: a full Watchlist panel in the sidebar with multiple lists, sections, tags and notes, drag and drop, and JSON import and export. It replaces the per-provider popular-symbol chips.
- **More data providers**: Coinbase, Kraken, Bybit and OKX, plus browsable symbol search with full symbol lists and add-to-watchlist.
- **Fixes**: the chart no longer vanishes when the sidebar is closed, and live errors now collect in an inbox.
- **Node 24** is now the default for the Docker image and recommended for local runs; Node 20.19+ is still supported.
- **Versioning**: the version now shows in the top bar and `/api/health`, and releases are tagged and published automatically.

No breaking changes: saved browser data, the API and deploy config are compatible with 0.1.0. To deploy, build from the tag (`git checkout v0.2.0`, then `docker compose up -d --build`); no registry image is published.
