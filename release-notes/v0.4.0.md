Market data now comes through the Vost server, and history can be fetched by time span.

## Highlights

- **Server-side market data**: every remote REST data path (Binance, Coinbase, Kraken, Bybit, OKX, Yahoo and Stooq) now runs on the Vost server instead of in the browser through `/api/proxy`. New endpoints: `/api/providers`, `/api/history`, `/api/symbols` and `/api/search`. Upstream errors name the provider and show in the toast. Live websocket feeds are unchanged.
- **Time spans on /api/history**: `/api/history` takes optional `from` and `to` (unix seconds). With `from`, every remote provider returns exactly the candles in the span, or a clear error when the provider has no data that far back. With `to` and `bars`, it returns the last `bars` candles ending at `to`. Requests without `from`/`to` behave as before.
- **Dev tooling**: dev-system updated to 0.101.0.

## Breaking changes

- **Node 20 is no longer supported.** Vost needs Node 22.18 or newer (`engines` is `>=22.18`); the server exits with a message on older versions.
- **`/api/proxy` is removed**, along with its `ALLOWED_HOSTS` host allowlist and the `VITE_DIRECT` and `VITE_PROXY_PREFIX` build options.
- **Static-only hosting** (the client without the Vost server) now supports only CSV import and Demo data.

Saved browser data stays compatible with 0.3.0; the old browser symbol-list caches are cleared once on first load. To deploy, build from the tag (`git checkout v0.4.0`, then `docker compose up -d --build`); no registry image is published.
