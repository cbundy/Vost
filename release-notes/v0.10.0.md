Vost now shows several charts at once: 1 to 16 charts in 55 arrangements, with one active chart that the top bar and panels follow, Sync in layout switches that carry symbol, interval, crosshair, time and date range across the charts, and named layouts you can save, autosave, copy, rename and reopen. The timeframe picker also takes any custom interval.

## Highlights

- **Chart layouts**: the "Select layout" button at the left of the top bar opens 55 arrangements of 1 to 16 charts. Click a chart to make it active (it gets an accent outline); the top bar, dock, Pine pane and watchlist act on the active chart. Going to more charts copies the active chart's market, timeframe and bars into the new ones; going to fewer keeps the first ones and stops the rest. Drag the dividers to resize (double-click resets them to even). On narrow screens only the active chart shows, with a switcher ("2 / 4", previous, next and a menu by market and timeframe).
- **Sync in layout**: five switches in the layout picker (Symbol, Interval, Crosshair, Time, Date range). With one on, a change on one chart follows on every other chart. Crosshair is on by default, the rest off. A chart whose provider does not serve a synced interval keeps its own, with a toast naming it.
- **Named layouts**: the layout's name sits in the top bar (in the More menu on narrow screens) and opens a menu: Save layout (Ctrl+S or Cmd+S, which no longer opens the browser's save dialog), Autosave (on by default), Make a copy, Rename, Create new layout, up to 5 recently used layouts, and Open layout (also the `.` key) with search and delete. With autosave off, a dot after the name marks unsaved changes and switching layouts asks Save, Don't save or Cancel.
- **Download chart data**: from the layout menu, download the active chart's bars or every chart's as `<symbol>_<timeframe>.csv` files.
- **Custom intervals**: the timeframe picker ends with **Add interval...**. Enter a number and a unit (for example 2h, 10m, 3d, 2w or 3M); the dialog previews what it is built from and refuses an interval outside the limits, one already listed, or one the provider cannot serve or build. Up to 20 are kept, listed by bar length and marked `*`, and hidden (not removed) on a provider that cannot serve them. The demo provider now generates any interval. Removing one moves every chart on it to the provider's default timeframe.
- **Drawings with several charts**: charts share one drawings store per tab, so charts on the same market see each other's drawings and one chart's save no longer overwrites another's. Drawing shortcuts (Escape, undo, redo, Delete) act only on the active chart.

## Upgrade notes

- **No server, API, environment or deploy change.** Every change in this release is in the browser app. Layouts, named layouts and custom intervals are stored only in the browser's localStorage, not on the server: they do not follow you to another browser or device, are not in `VOST_DATA_DIR`, and are not covered by backing up `alerts.json`. No new endpoint, variable, outbound host or proxy rule. Sixteen live charts still share one `/api/live` stream per tab (added in v0.9.0).
- **Saved browser data: no migration, older data still loads.**
  - New key `vost.layout.v1`: the working layout (arrangement, charts, divider sizes, active chart and the Sync flags), written on every change. On the first start of v0.10.0 it is absent, so you get one chart built from your existing `vost.prefs.v1`, exactly as before. If it is unreadable or does not match its arrangement, the app falls back the same way. A missing or bad `sync` field takes the defaults.
  - New key `vost.savedLayouts.v1`: the named layouts, each holding the same snapshot as `vost.layout.v1`, plus the Autosave flag. The first start, or a corrupt value, creates one layout named "Unnamed" from the working layout and changes no other key.
  - `vost.prefs.v1` keeps its flat shape and is still written from the active chart. It gains `customTimeframes` (your custom intervals; empty when absent, and bad entries are dropped).
  - `vost.drawings.v1` is unchanged in format.
  - **Downgrade**: v0.9.0 ignores the two new keys and opens one chart, the one that was active, from `vost.prefs.v1` (on a custom interval it falls back to the provider's default timeframe). Your layouts stay in the browser and come back if you upgrade again.
- **Clearing site data** for the Vost origin removes your layouts and named layouts along with the other browser settings. Use Download chart data if you need the bars; layouts themselves have no export yet.

To deploy, build from the tag (`git checkout v0.10.0`, then `docker compose up -d --build`); no registry image of the app is published. Nothing in your environment or `.env` needs to change.
