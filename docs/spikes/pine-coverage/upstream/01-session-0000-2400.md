# time() throws "Invalid session specification" for the session "0000-2400"

PineTS version: 0.13.0. Probe case: `session-time / time-session-0000-2400` in `../output.txt`. Draft only; the owner files it.

## Script and reproduction

```js
import { PineTS } from 'pinets';
// raw PineTS, array data
const data = Array.from({ length: 120 }, (_, i) => ({
  openTime: (1699920000 + i * 86400) * 1000, closeTime: (1699920000 + (i + 1) * 86400) * 1000 - 1,
  open: 100 + i * 0.3, high: 102 + i * 0.3, low: 98 + i * 0.3, close: 101 + i * 0.3, volume: 1000,
}));
const ctx = await new PineTS(data, 'TEST', 'D').run(`//@version=6
indicator("s")
plot(time(timeframe.period, "0000-2400") ? 1 : 0, "in session")`);
console.log(ctx.plots["in session"].data.at(-1).value);
```

## Expected (TradingView)

TradingView accepts `0000-2400` (a full day) and returns the bar time inside the session, so the plot is 1 on every bar.

## Actual (PineTS 0.13.0, from `output.txt`)

`pinets : ERR Invalid session specification: "0000-2400"`. `0000-2359` works (case `time-session-0000-2359`).
